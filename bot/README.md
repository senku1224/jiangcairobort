# 酱菜冒险者公会 · QQ 机器人（本机后端）

用 [NapCat](https://github.com/NapNeko/NapCatQQ)（OneBot v11）把 QQ 群和招募网站连起来。
**当前阶段只做只读**：`/招募`、`/网站`、`/帮助`。写入与身份（`/绑定`、`/报名`、`/我的`）等接入身份系统后再实现，不会假装已完成。

## 它怎么工作

```
QQ 群 ──消息──▶ NapCat ──HTTP 上报──▶ 本机 bot（本目录）
                                        │
                                        ├─ 读：Supabase REST（publishable key，只读）
                                        └─ 回：调用 NapCat HTTP API 发消息
```

零 npm 依赖，只用 Node 内置模块。默认监听 `127.0.0.1:8790`。

## 一、准备 NapCat

1. 到 NapCat 官方 Release 下载 **Windows 版**（一键包），解压启动。
2. 打开 NapCat 的 WebUI，用**手机 QQ 扫码登录**（建议用小号，别用常用大号）。
3. 在 WebUI 的「网络配置」里加两项：
   - **HTTP 服务器**：端口 `3000`（Token 可留空或自设，需与 `.env` 一致）——供本机 bot 发消息。
   - **HTTP 客户端 / 上报**：URL 填 `http://127.0.0.1:8790/onebot`，消息格式选 **array**，勾选上报群消息。
4. 把机器人小号拉进目标 QQ 群（或群主邀请）。

## 二、配置并启动本机后端

```bash
cd bot
cp .env.example .env      # 按需修改（QQ 群号、Token 等）
cd ..
npm run bot
```

看到「机器人后端已启动」即可。在群里 **@机器人 /招募** 或直接发 **/招募** 试试。

`.env` 已被 `.gitignore` 忽略，不会上传仓库。**绝不要把 `SUPABASE_SERVICE_KEY` 写进前端或发到聊天里。**

## 三、指令一览

| 指令 | 说明 |
| --- | --- |
| `/招募` | 列出当前开放中的招募（游戏、时间、剩余席位） |
| `/网站` | 返回招募网站链接 |
| `/帮助` | 指令说明 |
| `/绑定`、`/报名`、`/我的` | 占位：等身份系统接入后开放 |

## 四、保持运行

机器人是常驻进程，**本机关机 / 睡眠就下线**。想让它在群里一直在线，需要一台常开设备（自己长期开机的电脑，或便宜的小云服务器）。开机自启可用 Windows「任务计划程序」。

## 五、安全边界（重要）

- 当前没有登录身份，机器人以事件里的 **QQ 号** 为准，绝不信昵称。
- 只读阶段只用 publishable key；等做写入/绑定，才需要在本机 `.env` 放 **service key**，并且只放这里。
- NapCat 是第三方方案，登录真实 QQ 号有**风控封号风险**，用小号、控制频率。
